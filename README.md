Eine scrollbasierte 3D-Web-Experience, die mein Projekt erzählerisch und visuell aufbereitet – inklusive Poster und ausführlichem theoretischem Teil als PDF.

## ✨ Features

- 🪐 Immersives **3D-Scrollytelling**
- 🖼️ Projekt-Poster
- 📄 Theoretischer Teil (PDF)
- 📱 Responsive Darstellung

## 🛠️ Tech-Stack

`HTML5` · `CSS3` · `JavaScript` · `Three.js`
